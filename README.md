# BakerIN — Bakery Website

**Parwaaz AI Bootcamp · Day 1 · 26 August 2026**

A single-page website for a bakery brand called **BakerIN** — one `index.html`
file, no frameworks, no backend.

But the real point of day 1 wasn't the website. It was learning to work *with*
an AI coding agent. The site is just what came out of it.

## What we learned on day 1

- **Claude Code** — using an agentic coding tool properly instead of copy-pasting
  from a chat window, and how much faster that makes things
- **Modes** — when to plan first and when to just let it build
- **Models** — the different models available and which one to pick for which
  kind of task
- **MCP basics** — how Claude Code connects to outside tools and services
- **Vercel** — deploying a project so it's live on the internet
- **Supabase** — what it is and where a database and backend fit in later
- Writing clear prompts, and reviewing what the agent gives back instead of
  trusting it blindly

## About the site

Built in one go with Claude Code. It has a sticky navigation bar, a hero
section, the five things BakerIN sells (fresh chocolates, custom cakes, cake
tins, fresh bakery items and advance cake bookings), a "why choose us" section,
a custom cake booking form, contact details, a WhatsApp ordering button and a
footer. Fully responsive, so it works on a phone and a laptop.

## How to open it

Double-click `index.html`, or open it in any browser. That's it.

## Before using it for real

The phone number, WhatsApp number, address and email are placeholders. They're
marked with comments inside `index.html` — search for `PLACEHOLDER` and replace
them.
