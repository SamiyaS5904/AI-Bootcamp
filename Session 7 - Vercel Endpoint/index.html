How this page works

  • The buttons call the API with fetch() using relative paths, so the same page works on localhost and on Vercel.
  • Vercel turns each file in /api into a serverless function named after it — api/status.js becomes /api/status, with no server code.
  • Try an unknown id such as a99 to see the 404 response, or clear the field to see 400.
  • Appointment ids in the sample data run from a27 to a31.
