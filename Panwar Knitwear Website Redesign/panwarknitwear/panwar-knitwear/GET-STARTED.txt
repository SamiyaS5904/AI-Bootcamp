PANWAR KNITWEAR — how to run this
=================================

1. Install Node.js 18 or newer if you don't have it:  https://nodejs.org
2. Unzip this folder anywhere you like, e.g.
      Windows:  C:\Users\<you>\Desktop\panwar-knitwear
      Mac:      ~/Desktop/panwar-knitwear
3. Open a terminal in that folder and run:

      npm install
      npm run dev

4. Open the address it prints (usually http://localhost:5173).

To build the production files:

      npm run build

...which writes a `dist/` folder. That folder is the whole website — upload it
to any static host (Netlify, Vercel, Hostinger, cPanel, S3). Nothing else is
needed; there is no server to run.

BEFORE IT GOES LIVE
-------------------
- Set Vercel's Root Directory to this folder and commit vercel.json, or
  /catalogue will 404 on a direct link or a refresh.
- The enquiry form hands off to WhatsApp and nothing is logged server-side.
  Supply a real email address if you want a durable record of enquiries.
- Replace the remaining bracketed placeholders — {{MOQ}}, {{fit}}, {{GSM}},
  {{GSM range}}, {{size set}} — in src/data/company.js and
  src/data/products.js as the figures are confirmed.
- Update SITE_URL in src/lib/meta.js, the canonical and og:* URLs in
  index.html, and public/sitemap.xml when panwarknitwear.com cuts over to
  this build. They currently point at the Vercel domain on purpose, because
  the OLD site is still live on panwarknitwear.com.

Full notes are in README.md.
